# Exercise photos

Start/end position photos come from [free-exercise-db](https://github.com/yuhonas/free-exercise-db) by yuhonas, released into the public domain under the [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE).

Files are renamed to the app's exercise keys: `<key>-0.jpg` is the start position, `<key>-1.jpg` the end position. The source folder for each key is listed in the `DEMO` map in `index.html`.
